# TV remote navigation

Fullscreen Up/Down tunes the previous/next channel whether controls are visible or hidden. Left/Right reveals controls and moves the horizontal cursor. Select activates its option. Inside the dot menu and submenus, arrows move between options without tuning.

Entering fullscreen focuses Play/Pause. Quality, Audio Tracks and Subtitles open with the current setting selected and marked. Quality lists Auto, 1080p, 720p, 480p, 360p where supported. Tracks list the profile language first, then English; subtitle Off remains first. Back returns from a submenu to the dot menu, then closes the menu, hides controls and returns to the guide.

Guide arrows update the details beside the preview using the selected program’s existing metadata; browsing does not retune playback. Commercials are omitted from TV guide cells and navigation. Continuation segments of a show split by commercials are joined into one cell; fresh airings remain separate. Arrows advance between shows, resolve gaps consistently and keep selection visible. Timeline headers always align to hours and half-hours; 12:44 AM initially shows 12:30 AM, 1:00 AM, 1:30 AM and so on, regardless of program start times.

The guide receives default focus. Arrows wrap between channels and programs. Back restores the watched airing; when already focused there, Back opens the profile menu with Switch Profile focused. A second Back within two seconds exits to Google TV Home. Otherwise Back closes the menu and restores the watched airing. Menu arrows stay within the popup and cancel double-Back exit. Exit App below Sign Out also closes the app, preserving the saved session.

After the first profile selection or restoration, a static remote tutorial appears once per installation. **Got it** or Back dismisses it and opens the guide. The acknowledgement survives updates and sign-out; uninstalling resets it. The tutorial mounts no player/guide and has no animations or timers.

**AlreadyOn TV Test** updates preserve its encrypted session; uninstalling removes it. See [device review](TV_DEVICE_REVIEW.md) for the physical remote checks.

Background loading has no animated TV status bar; errors remain visible.

The guide keeps the player preview mounted across fullscreen changes and reserves space for the profile menu. [TV profile settings](TV_PROFILE_SETTINGS.md) replace the player/guide while editing.
