01 / FIND YOUR WAY AROUND

Find your way around

AlreadyOn turns a library you supply into scheduled channels. Choose a channel to join its current airing; you may arrive partway through a program. Everyone watching that channel follows its schedule rather than starting a separate on-demand episode.

This guide covers the WebUI, Android phone/tablet app and Google TV app. The browser is also where you manage your server. First-time host? Start with the server installation walkthrough, then return here.

Which version are you using?These guides describe the current development cycle. Compare your installed version with GitHub Releases; an older Stable app may not include every option yet.

02 / THE GUIDE AND PLAYER

The guide and player

  1. Sign in, select a profile and open the Guide. Current and upcoming programs are arranged beside each channel.
  2. Select an airing/channel to tune in. Grey ended airings are history, not replay buttons. Real gaps can remain when no program was scheduled.
  3. Use the small player while browsing. Expand it or enter fullscreen when you want to watch; return to the guide to see what is next.
  4. Open the three-dot menu for Quality, Audio Tracks and Subtitles. Only tracks supplied by the current file are offered.

Quality shows Auto or your selected resolution. Audio Tracks shows a language only when it can be determined. Subtitles shows on/off. A quality choice still depends on the server’s delivery path and the media; selecting a high resolution cannot add detail that is absent from the source.

Channel surfing follows the visible, playable lineup, skipping empty channels and wrapping at either end. Player settings carry across channel changes where matching tracks are available. Opening a menu changes what arrows do: they navigate the menu instead of tuning another channel.

Use playback details when investigating a stall: Local Buffer is playable media already buffered locally; Live Delay is the distance from the live stream edge. These describe different things.

Keyboard shortcuts apply while navigating playback, not while typing into a settings field. Use browser zoom and your operating system’s text/accessibility controls for readability; AlreadyOn does not include brightness or font-size sliders.

04 / GOOGLE TV REMOTE

Google TV remote

The guide opens with the watched airing focused. D-pad arrows browse programs and channels and wrap at the ends. Program details follow the highlighted selection; Select tunes it and opens fullscreen. The preview itself has no selectable playback controls.

Single Back, double Back and Exit App

When the watched airing is already focused, one Back opens the profile menu with Switch Profile selected. A second Back within two seconds exits to Google TV Home. A later Back closes the menu and restores the guide. Navigating the menu cancels quick exit. Exit App, below Sign Out, also returns Home without signing out. Every menu option has the same white focus outline.

After profile selection, the guide opens directly on the saved channel or first available channel.

05 / PROFILES AND SUBTITLE PREFERENCES

Profiles and subtitle preferences

Open the top-right avatar/name control. Switch Profile changes the viewer and respects profile PINs; Profile edits the current profile. WebUI also shows Settings to Admin profiles and Server to owner accounts. Google TV adds Exit App. Profile roles and account ownership are separate.

Switch Profile lists the current profile first, then other names alphabetically. In the WebUI, an Admin profile can choose Add Profile, enter a name, select Admin/Viewer and Kids/Teen/Unrestricted, then Create. The new profile becomes available without replacing the current selection.

Profile settings include display name, icon, PIN, time format, preferred audio language, subtitle language and subtitle mode. Save Changes saves the edited preferences; Cancel discards drafts. PIN changes/removal have separate actions. On TV, Up/Down previews categories, Select/Right enters their controls, and Back moves to the category before leaving settings. Upload custom profile images in the WebUI.

Subtitle modeUse it when…
Always onYou want available captions in your chosen subtitle language.
For other audioYou want captions when the playing audio differs from your preferred audio language.
OffYou want to select captions manually in the player.

For example, preferred English audio plus English subtitles in For other audio mode enables captions for Japanese audio, then turns automatic captions off when you choose English audio. Unknown audio or missing subtitles leaves playback uninterrupted. English appears first in language selectors; other languages follow alphabetically. Shared profile preferences refresh across active clients and on resume while preserving local drafts.

06 / ACCOUNTS, PINS AND SESSIONS

Accounts, PINs and sessions

Use WebUI Settings for the account’s username/password, TV Pairing PIN and Sessions. The account’s 6–12 digit TV PIN signs native apps into the server; it is different from a profile PIN, which protects switching to a profile. Changing the account PIN affects new sign-ins rather than disconnecting existing sessions.

Sessions shows Device, IP Address, Last Active, Expires and Sign Out. The current session appears first with This Session; the remaining sessions sort by recent activity. Scroll wide tables horizontally on a phone. Sign out an individual device when it should no longer have access; Sign Out All Other Sessions and Sign Out Everywhere have wider effects.

Manage household accounts and profiles

Owners use Server → Home Users → Add Account to give another person their own username/password and Owner/Viewer account role. Edit their enabled status, password policy and Simultaneous Streams limit when needed; 0 means unlimited. A closed device can take up to five minutes to release its stream slot. Account deletion and broad sign-out affect real access, so confirm the intended person before applying them.

The WebUI Settings page also lists profiles with Name, Role, Audience and PIN. Add/edit profiles there or use the Admin-only Add Profile shortcut in Switch Profile. Admin/Viewer here is a profile role, separate from the account’s Owner/Viewer role. Profile deletion removes that viewer profile; it does not delete media.

Stay Signed In For (Days) and Never Expire control browser session expiry. Owner-only Remove Inactive Sessions defaults to On and 14 days, including sessions that otherwise never expire. Day fields save on blur with a brief confirmation; toggles apply immediately.

Native Sign Out detaches the selected server but retains its encrypted session. Selecting that recent server revalidates it and can skip account credentials; revocation, expiry or account restrictions require sign-in again. Profile PINs still apply. Exit App simply closes the TV app.

07 / MEDIA AND METADATA

Media and metadata

Owners open Server → Media. Add TV Show Folders and Movie Folders using paths inside the container, such as /data/media/TV. Host paths only work when mounted into the container. Folder status and item counts help identify missing paths or permissions problems.

Refresh Media scans now. New files enter the catalog, missing files leave it, and future schedules are updated without treating a refresh as permission to reset current airings. Polling Interval controls automatic checks, from 15 minutes to 24 hours; the default is one hour.

Under Server → Server, Free Metadata Sources can provide metadata without a TMDb key. For TMDb, enter an API Read Access Token—the long token, not the short API key—and use Set. Setting it disables the free-source option. Clear removes the integration credential. Metadata availability changes which genre, rating and era filters can match; a key does not repair an unreadable media path.

Saved provider secrets stay masked and are not returned to the form. Eye controls reveal only a replacement draft you have entered. Keep tokens private.

08 / BUILD AND CONFIGURE CHANNELS

Build and configure channels

  1. Open Server → Channels and review the current lineup. Built-in channels depend on available media and metadata; empty channels may be hidden.
  2. Choose Create Custom Channel, or Edit beside an existing channel. Set its number and name; numbers 100–199 are reserved, so custom channels start at 200.
  3. Choose the audience/rating restriction, Shows Or Movies, included Genres, Excluded Genres, Era and optional Title Contains phrases. Excluded genres win when rules overlap. Require Known Premiere Year removes items with missing years.
  4. Limit Included Media Paths if this channel should use only selected folders. Check the live preview/match count before saving; zero matches means there is nothing eligible to schedule.
  5. Set per-channel commercial enablement and paths if needed, then save. Use the Guide Schedule update action when you need to refresh future coverage and watch its Last Updated status.

Visibility and reusable filters

A channel’s visibility cycles through Hide, Show and Auto. Hide removes it from the guide, Show requests visibility, and Auto shows it when media matches. Select rows for Hide Selected, Show Selected or Set to Auto. These actions change the lineup display rather than deleting source files.

Configure Filters defines reusable Age Restrictions and Eras. Set rating inclusion and unknown-rating handling for restrictions, or start/end years for eras. Give each a clear name, then choose it in channel editors. Drag rows to reorder; touch uses a long press, and focused reorder controls support Up/Down. Restore Default restores the default order. Review which channels use a filter before changing or deleting it.

Restricted lineups need usable ratings; missing metadata must not be treated as known-safe content. The built-in Classic/Modern split uses the series premiere year, with Classic ending in 2009. Avoid overlapping custom numbers and give channels clear names.

Changing a filter shapes eligible programming; it is not a way to edit or replay an already published airing. If a channel is empty, check metadata, path selection and exclusions before widening every rule.

09 / COMMERCIAL BREAKS

Commercial breaks

Commercials are optional clips you supply. Under Server → Commercials, add Commercial Folders, then enable Commercial Breaks. AlreadyOn does not download advertising or provide a commercial library.

SettingEffect
ModeBetween Episodes/Movies Only, or breaks every 15, 30 or 60 minutes.
TV / Movie Commercials Per BreakChoose separate numbers of clips for TV episodes and movies.
Commercial Volume Offset (dB)Adjust commercial playback relative to program audio; the control accepts −30 to +12 dB.
Per-channel Enable Commercials / Commercial PathsEnable or disable breaks for that channel and restrict the clip pool; timing, count and volume are global.

Save Changes applies the global draft. Folder edits have their own saving/status behavior. An inherited per-channel enablement uses the server default; an unrestricted commercial path selection uses the configured pool. If no eligible clips exist, check folder scanning before changing timing. Original media files are not edited, and playback has no Delete Commercial action.

10 / INSTALL AND CONNECT THE APPS

Install and connect the apps

  1. Open GitHub Releases. Select the release you intend to test and download alreadyon-android.apk for phone/tablet or alreadyon-tv.apk for Google TV.
  2. Install the signed APK. Allow installation from the app/file source you are using when Android requests it.
  3. Set your account’s TV Pairing PIN in WebUI Settings, then launch the native app.
  4. Choose a discovered server. Discovery scans the local private IPv4 network for about 30 seconds; manual entry remains available while it runs.
  5. For manual entry, enter only Hostname / IP and a separate Port. IP addresses suggest 19900; hostnames do not. An empty port means HTTPS 443, not a hidden fallback to 19900. IPv6 accepts optional brackets.
  6. Connect on a trusted LAN, sign in with username and account PIN, then choose a profile. Guest Wi-Fi isolation and firewall rules can block discovery or sign-in.

The apps save the selected instance’s certificate trust locally, without a device-wide CA import. If saved trust later fails, Review Server CA offers an explicit replacement decision; investigate the change before accepting a new CA. PIN sign-in requires a direct LAN peer; an internet-facing proxy does not replace that requirement.

11 / APK AUTO-UPDATE

APK auto-update

Signed phone and TV apps check GitHub at startup without blocking viewing. Update Available shows installed/available versions and Update/Cancel. Stable installs follow Stable releases; preview installs can accept alpha/RC/Stable. A preview APK promoted unchanged to Stable follows Stable once its matching artifact is published there. Reused version codes do not prompt again.

  1. Choose Update to download the APK for your device. The app checks its checksum, package, phone/TV target and signing certificate.
  2. Allow AlreadyOn to install updates if Android requests that permission, then approve the system installer.
  3. After replacement, the app attempts to reopen and removes the downloaded APK. Use Open or launch manually if the operating system does not reopen it.

Cancel stops the download/install preparation. An interrupted staged install can offer Continue Installation or Cancel on reopening. A failed or offline update check stays quiet. Normal signed updates preserve settings and saved sessions; debug apps skip production update checks. Install the first updater-capable release manually.

Server container updates are separate: see maintenance and backups.

Loudness Detection

This is off by default. Enable it to analyze playback audio, then use Run Now to process outstanding files or retry failures. Current File, Workers, Processed, Pending, Skipped, Failed and Limited By explain its progress. Missing measurements play at their original volume. Measured audio is normalized during playback, which can use additional CPU and a streaming worker and add startup time; original media stays intact. Disabling stops background analysis while retaining measurements, and playback changes apply at the next tune or program transition.

Use Save Changes for page drafts unless a setting supplies an immediate action, such as Set/Clear, a session toggle or a folder edit. Read the displayed status and More Info text rather than assuming every page saves the same way. Restart controls interrupt active use; coordinate with other viewers.

13 / GET HELP AND REPORT ISSUES

Get help and report issues

Check the container/app version, media path permissions, selected device and relevant timestamps first. For a playback problem, include the codec/container, browser/device, whether transcoding was active and the exact visible error. A synthetic reproduction is helpful; never upload your database or media.
