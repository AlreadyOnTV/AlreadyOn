# Assistant entry point

Follow [AGENTS.md](AGENTS.md). It contains the shared rules for all coding assistants.

Start with [the project brief](docs/PROJECT_BRIEF.md), [contributing](CONTRIBUTING.md) and [delivery](docs/CI_CD.md). Check ignored `.private/AGENTS.md` when it exists for maintainer-specific procedures.

Keep changes reviewable, preserve unrelated work, use isolated tests and report verified results. Develop on `dev`; release PRs target `main` and use the validated Nightly/Stable workflows.
